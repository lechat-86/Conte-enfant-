## Notre position
**Atouts [H]** : délai ≈ 1 h ; prix d'achat unique ; fichiers MP3 + WAV 8 kHz ; texte rédigé pour le métier ; pas d'abonnement ; 2 voix.
**Faiblesses** : voix de synthèse (certains préfèrent l'humain) ; aucune preuve sociale au départ ; pas de musique/habillage sonore ; pas d'installation chez le client ; marque inconnue ; dépendance à ElevenLabs/Claude.
**Cannibalisation** : les standards IA (49 €/mois) répondent aux appels, nous non : notre promesse est « un bon message », pas « un secrétariat ». Ne pas les concurrencer sur ce terrain.
