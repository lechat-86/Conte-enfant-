# Grille de validation / Validation scorecard

> **Fixer les seuils AVANT les entretiens** et ne pas les modifier après coup. Les seuils ci-dessous sont des propositions de départ, ajustables une seule fois en amont.
> **Set the thresholds BEFORE the interviews** and do not change them afterwards. The thresholds below are starting proposals, adjustable once, upfront.

---

## 🇫🇷 Français

### 1. Échelle d'engagement (par cabinet)
| Niveau | Signal | Valeur |
|---|---|---|
| 0 | Politesse (« intéressant ») | Aucune |
| 1 | Douleur confirmée avec exemple concret | Faible |
| 2 | Demande à revoir une version plus avancée | Moyenne |
| 3 | Présente un collègue / l'associé | Forte |
| 4 | Accepte un pilote sur cas non sensible, par écrit (lettre d'intention) | Très forte |
| 5 | Paie (même modestement) ou pré-engage un budget | Preuve |

### 2. Critères notés (0 à 5) — à remplir sur l'ensemble des entretiens
| # | Critère | Poids | Comment noter (0 = non, 5 = très net) | Note | Points = poids × note / 5 |
|---|---|---|---|---|---|
| 1 | Intensité et fréquence de la douleur (exemples concrets, temps déclaré) | 20 | Part des cabinets citant un exemple récent précis | | |
| 2 | Priorité (top-3 des irritants) | 10 | Part des cabinets le classant top-3 | | |
| 3 | Insuffisance des alternatives actuelles | 10 | Part des cabinets dont l'outil actuel ne couvre pas contrôle + relance | | |
| 4 | Désirabilité après démo | 10 | Réactions spontanées positives, demandes de fonctions | | |
| 5 | Engagement (échelle ci-dessus) | 20 | Niveau moyen / nombre de niveaux 3–5 | | |
| 6 | Signal de prix | 15 | Cabinets acceptant un prix de la grille ≥ plancher (voir `PRICING_TEST.md`) | | |
| 7 | Faisabilité perçue (fiabilité requise atteignable, exigences données/RGPD tenables) | 10 | Exigences déclarées vs capacités réalistes | | |
| 8 | Accessibilité du marché (canal d'acquisition identifiable, cycle d'achat court) | 5 | Qui décide, en combien de temps, par quel canal | | |
| | **Total** | **100** | | | |

### 3. Verrous obligatoires (tous requis pour un « Go », quel que soit le score)
| Verrou | Seuil proposé | Atteint ? |
|---|---|---|
| G1 — Entretiens qualifiés réalisés (cabinets de la cible) | ≥ 10 | |
| G2 — Cabinets au niveau d'engagement ≥ 4 | ≥ 3 | |
| G3 — Signal de paiement : au moins 1 niveau 5, ou ≥ 3 cabinets acceptant explicitement le plancher de prix | ≥ 1 ou ≥ 3 | |
| G4 — Aucun point bloquant non traitable (données, conformité, fiabilité exigée) cité par une majorité | Aucun | |
| G5 — Problème confirmé *sans* que j'aie suggéré la réponse (section 2 de l'entretien, avant la démo) | ≥ 6 cabinets | |

### 4. Décision
| Score | Décision |
|---|---|
| ≥ 75 **et** tous les verrous | **GO** : construire un MVP étroit (1 type de pièce, 1 pays) avec pilotes sous contrat |
| 55 – 74, ou un verrou manqué | **ITÉRER / PIVOTER** : cibler un segment plus précis, changer l'offre, refaire 5 entretiens |
| < 55 | **STOP / REPENSER** : la demande n'est pas démontrée ; ne pas investir dans le développement |

### 6. Règles de lecture
- Les temps gagnés ou perdus cités sont des **déclarations**, pas des mesures.
- « Je serais intéressé » ne compte pas ; un engagement écrit ou un paiement compte.
- Un échantillon de ~10–15 entretiens donne un **signal qualitatif**, pas une preuve statistique.
- Distinguer biais de politesse, biais d'amitié (ne pas compter proches/famille) et biais de sélection.
- Décider à la date prévue ; ne pas « un entretien de plus » pour sauver un résultat.

## 🇬🇧 English

### 1. Commitment ladder (per firm)
| Level | Signal | Value |
|---|---|---|
| 0 | Politeness (“interesting”) | None |
| 1 | Pain confirmed with a concrete example | Low |
| 2 | Asks to see a more advanced version | Medium |
| 3 | Introduces a colleague / the partner | Strong |
| 4 | Agrees to a pilot on a non-sensitive case, in writing (letter of intent) | Very strong |
| 5 | Pays (even modestly) or pre-commits a budget | Proof |

### 2. Scored criteria (0–5) — fill in across all interviews
| # | Criterion | Weight | How to score (0 = no, 5 = very clear) | Score | Points = weight × score / 5 |
|---|---|---|---|---|---|
| 1 | Pain intensity and frequency (concrete examples, stated time) | 20 | Share of firms citing a precise recent example | | |
| 2 | Priority (top-3 irritants) | 10 | Share of firms ranking it top-3 | | |
| 3 | Inadequacy of current alternatives | 10 | Share of firms whose current tool does not cover checking + follow-up | | |
| 4 | Desirability after demo | 10 | Spontaneous positive reactions, feature requests | | |
| 5 | Commitment (ladder above) | 20 | Average level / number of levels 3–5 | | |
| 6 | Price signal | 15 | Firms accepting a grid price ≥ floor (see `PRICING_TEST.md`) | | |
| 7 | Perceived feasibility (required reliability achievable, data/GDPR requirements manageable) | 10 | Stated requirements vs realistic capabilities | | |
| 8 | Market reachability (identifiable acquisition channel, short buying cycle) | 5 | Who decides, how fast, through which channel | | |
| | **Total** | **100** | | | |

### 3. Mandatory gates (all required for a “Go”, whatever the score)
| Gate | Proposed threshold | Met? |
|---|---|---|
| G1 — Qualified interviews completed (target firms) | ≥ 10 | |
| G2 — Firms at commitment level ≥ 4 | ≥ 3 | |
| G3 — Payment signal: at least 1 level-5, or ≥ 3 firms explicitly accepting the price floor | ≥ 1 or ≥ 3 | |
| G4 — No unresolved deal-breaker (data, compliance, required reliability) cited by a majority | None | |
| G5 — Problem confirmed *without* me suggesting the answer (interview section 2, before the demo) | ≥ 6 firms | |

### 4. Decision
| Score | Decision |
|---|---|
| ≥ 75 **and** all gates | **GO**: build a narrow MVP (1 document type, 1 country) with contracted pilots |
| 55 – 74, or a missed gate | **ITERATE / PIVOT**: narrow the segment, change the offer, run 5 more interviews |
| < 55 | **STOP / RETHINK**: demand is not shown; do not invest in development |

### 6. Reading rules
- Time saved or lost figures are **statements**, not measurements.
- “I’d be interested” does not count; a written commitment or a payment does.
- A sample of ~10–15 interviews gives a **qualitative signal**, not statistical proof.
- Separate politeness bias, friendship bias (do not count friends/family) and selection bias.
- Decide on the planned date; no “one more interview” to rescue a result.
