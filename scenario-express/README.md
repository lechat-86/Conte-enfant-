# SCÉNARIO EXPRESS — kit complet de lancement

Boutique de produits numériques (scripts + prompts vidéo IA). Aucun stock, aucune livraison physique.

## Contenu du dossier
| Fichier | Rôle |
|---|---|
| `produits/pack-horreur-10.md` | Produit 1 : 10 histoires d'horreur d'1 minute (scripts + prompts) |
| `produits/pack-pubs-ugc-15.md` | Produit 2 : 15 trames de pubs UGC pour e-commerçants |
| `produits/echantillon-gratuit-camera-7.md` | Aimant à prospects : script offert contre un e-mail |
| `boutique/contenu-boutique.md` | Textes de la boutique : accueil, fiches produits, FAQ, e-mails |
| `boutique/legal-modeles.md` | Modèles : mentions légales, CGV, confidentialité, retours |

## Checklist de lancement

**Avant d'ouvrir**
1. Convertis les 3 fichiers de `produits/` en PDF (copier dans Google Docs ou Canva → télécharger en PDF).
2. Choisis ta plateforme : Shopify (abonnement après l'essai, vérifie les prix sur shopify.com) ou Gumroad (pas d'abonnement, commission sur les ventes).
3. Crée ton statut (micro-entrepreneur, par exemple) avant ta première vente.
4. Remplis les crochets de `boutique/legal-modeles.md`.

**Mise en ligne**
5. Crée les produits avec `boutique/contenu-boutique.md` : titres, descriptions, prix.
6. Ajoute les PDF en téléchargement numérique.
7. Active la case de renonciation au droit de rétractation à l'achat.
8. Publie les pages légales dans le pied de page.
9. Fais une commande test.

**Après le lancement**
10. Mets le lien dans ta bio TikTok/YouTube/Instagram.
11. Poste les vidéos tirées des scripts du pack (comme preuves).
12. Envoie l'échantillon gratuit à chaque nouvel abonné de ta liste.
13. Vends le service de production de vidéos aux e-commerçants (voir le plan de prospection).
