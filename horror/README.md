# La Maison des Murmures

Vidéo d'horreur en 3 parties (≈1 min 44) avec screamer, entièrement générée par `make_video.py`
(images PIL/numpy, son synthétisé, assemblage ffmpeg).

- Partie 1 – L'héritage
- Partie 2 – Le sous-sol
- Partie 3 – Elle (screamer à 1:36)

⚠ Le screamer est très fort : baissez le volume avant de lancer la vidéo.

Régénérer : `python3 horror/make_video.py` (nécessite ffmpeg, Pillow, numpy).
